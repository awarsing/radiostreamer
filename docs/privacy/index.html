Privacy

Privacy notice

Short version: this site does not use cookies and does not collect personal data.

Last updated: 2026-05-08

What we collect

Nothing personal. The site has no accounts, no forms, no comments, and no tracking pixels. There is nothing for you to log into and nothing to fill out.

Cookies

This site does not set any cookies. There is no cookie banner because there are no cookies to consent to.

Analytics

Basic traffic measurement uses Cloudflare Web Analytics, configured in server-side mode. It records aggregate request metrics (URL, response status, country at country-level granularity, referrer) without setting cookies, without fingerprinting visitors, and without sharing data with advertising networks. Cloudflare's privacy policy covers their handling of this data.

Hosting and logs

The site runs on a Cloudflare Worker with static assets served from Cloudflare's network. Cloudflare receives standard HTTP request metadata (IP address, user agent, requested URL) for routing, security, and abuse prevention purposes. We do not maintain a separate access log of our own.

Downloads

The macOS plugin download is served as a static Cloudflare asset. Downloads are anonymous; we do not associate downloads with individuals. Cloudflare may log download requests for abuse prevention, subject to Cloudflare's privacy policy.

Third-party links

This site links to GitHub, Cloudflare, the GNU project (for the GPL text), and similar resources. Their privacy policies apply when you visit them.

Tip Jar (Stripe and GitHub Sponsors)

The Tip Jar page links to a Stripe Payment Link and a GitHub Sponsors page so visitors can voluntarily fund development. Following either link takes you to a page hosted by Stripe or GitHub respectively. We do not see your card details, and we do not associate tips with site visits. Stripe receives the information needed to process the payment under their privacy policy; GitHub Sponsors operates under GitHub's privacy statement. The site itself does not embed any Stripe or GitHub scripts; the buttons are plain HTML links.

The plugin itself

The Radio Streamer plugin runs locally on your Mac inside OBS Studio. It does not phone home, does not check for updates over the network, and does not transmit any telemetry. It only opens network connections to the Icecast server you configure in the URL field.
